# JIPAS — Joy International School Website

Official website for JIPAS (Joy International School), Lomé, Togo.

Live at: https://joyintschool.github.io/jipas/

## Structure
Flat layout — every file sits in the repo root (no subfolders):
- `index.html` — the site (single page)
- `logo.png` — school crest
- `waec-logo.png` — WAEC seal
- `library.jpg`, `science-lab-1.jpg`, `science-lab-2.jpg`, `classroom.jpg`, `assembly.jpg`, `nursery.jpg` — gallery photos
- `JIPAS_Application_Form.pdf` — downloadable application form
- `robots.txt`, `sitemap.xml` — for search engine indexing

## Hosting
Deployed via GitHub Pages, Settings → Pages → Deploy from branch (main / root).
Redeploys automatically within about a minute of any file upload.

## Updating the site
Replace files directly in this repo (Add file → Upload files) — keep the flat structure, no subfolders.
