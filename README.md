# JIPAS — Joy International School Website

Official website for JIPAS (Joy International School), Lomé, Togo.

## Structure
- `index.html` — the site (single page)
- `assets/logo.png` — school crest
- `assets/gallery/` — school life photos

## Hosting
This site is deployed via GitHub Pages. Live at:
`https://YOUR-USERNAME.github.io/jipas-website/`

## Updating the site
Replace files in this repo and push/upload — GitHub Pages redeploys automatically within about a minute.
